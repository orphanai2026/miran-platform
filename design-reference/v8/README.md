## قواعد الدمج

1. V8 هو المصدر البصري الوحيد للمحاذاة والألوان والخلفية والناي وشريط التنقل.
2. تُدمج الوظائف الحالية داخل التصميم؛ لا يُستبدل التصميم بقالب تقريبي.
3. تبقى صفحة التمارين كما هي وظيفيًا وبصريًا، ويظهر فيها رابط «الرئيسية» بالأعلى فقط.
4. يظهر شريط التنقل السفلي في بقية الصفحات، بما فيها صفحة الدليل، مع تمييز الصفحة الحالية.
5. الأرقام المخفية في V8 تبقى مخفية في التنفيذ.
6. صورة الناي المرجعية لا تُرسم بـ CSS أو SVG ولا تُستبدل بصورة مولدة.
7. لا تُنقل القيم التجريبية من ملف المعاينة إلى منطق التطبيق؛ تُربط العناصر ببيانات المنصة الفعلية.
