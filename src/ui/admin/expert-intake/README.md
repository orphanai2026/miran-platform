# صفحة الخبير (إدارية) — `src/ui/admin/expert-intake/`

أداة جلسة تسجيل واحدة متصلة لبناء مكتبة الاستماع المرجعية (100 تسجيل نغمة
مفردة — 25 نغمة × 4 قيم إيقاعية (روند/بلانش/نوار/كروش)، القرار 13.1 —
+ 16 تسجيل مقام إلزامي — 8 مقامات × صعود+هبوط شائع، القرار 13.2 — + أي
هبوطات بديلة اختيارية يقرّرها الخبير حيًّا أثناء الجلسة) — القرارات
9.2/9.4/13.1/13.2 في `docs/miran-decisions-log.md`.

## نطاق مقصود — إدارية بحتة، لا جزء من رحلة المتدرب

- **غير مُدرَجة في `src/ui/shared/nav.js`** ولا في أي رابط بالصفحة
  الرئيسية — رابط مباشر فقط (`src/ui/admin/expert-intake/index.html`)،
  معروف للمالك/الخبراء المدعوّين تحديدًا.
- خارج مجلد `src/ui/pages/` عمدًا — إشارة بنيوية واضحة إنها ليست إحدى
  الصفحات الثماني الحية للمتدرب.
- لا إرسال شبكي، لا خادم — التسليم يدوي بالكامل (تنزيل محلي، ثم إرسال
  المالك للملفات خارج الموقع). نقطة Google Drive المقترحة **غير محسومة
  بعد** (القرار 9.4) — لم تُبنَ.

## البنية

| الملف | الدور |
|---|---|
| `index.html` | الصفحة نفسها، بنفس الهوية البصرية (كريمي/تركوازي/ذهبي)، شارة "إدارية" واضحة أعلاها |
| `expert-intake-data.js` | قائمة الجلسة الثابتة (100 نغمة = 25 × 4 قيم إيقاعية `RHYTHMIC_VALUES` + 16 مقام إلزامي = 8 مقامات × صعود/هبوط شائع) — مستوردة من `NOTES_24TET` (صفحة #4) و`ALL_MAQAMAT` (src/maqamat/)، **بلا أي تكرار للبيانة**. تصدّر أيضًا `createAlternateDescentItem()` لبناء عنصر هبوط بديل حيًّا وقت الجلسة (القرار 13.2) |
| `expert-recorder.js` | محرك الميكروفون: تغذية راجعة حيّة (`detectPitch` المُعاد استخدامه من `src/calibration/`) + التقاط PCM خام بالتوازي |
| `wav-encoder.js` | ترميز WAV خالص (رأس RIFF يدوي، PCM 16-bit) — **بلا أي مكتبة خارجية**، دالة خالصة قابلة للاختبار بـ Node مباشرة |
| `expert-id.js` | معرّف خبير محلي، نفس نمط `07-settings-sync/local-user-id.js` بمفتاح تخزين مختلف (`miran_expert_id_v1`) |
| `expert-intake-page.js` | آلة حالة الجلسة: تسجيل → معاينة (صوت + تردد مقاس تلقائيًا) → قبول/إعادة → تنقّل تلقائي → تنزيل الكل + بيان JSON عند الانتهاء |

## لماذا WAV فقط (لا MP3 هنا)

القرار 9.4 صريح: "لا حاجة لفتح استثناء `lamejs` لأداة يستخدمها خبير واحد
أو اثنان بمعدل نادر." استثناء `lamejs` (WAV+MP3) يبقى محصورًا بمكتبة
تسجيلات المتدرب الشخصية (القرار 9.3) لو نُفِّذت لاحقًا — لا يُفتح هنا.

## القياس التلقائي للتردد

عند إيقاف كل تسجيل، تُحسَب وسيط (median) كل القراءات الواضحة (جودة ≥ 0.6)
أثناء التسجيل، وتُعرَض للخبير فورًا كجزء من المعاينة، وتُرفَق تلقائيًا في
بيان JSON النهائي — الخبير لا يحتاج أي تحقّق رقمي أثناء العزف نفسه (القرار
9.2: "الخبير يعزف بأذنه بلا أي تحقّق رقمي أثناء العزف").

## بنية تسجيل المقام الثلاثية (القرار 13.2)

كل مقام من الثمانية يحمل حالتين إلزاميتين ثابتتين ضمن قائمة الجلسة
(`maqamPart: "ascend"` و`"descend-common"`) — 16 عنصرًا إجمالًا. حالة
ثالثة اختيارية (`"descend-alternate"`) **لا تدخل القائمة الثابتة إطلاقًا**؛
تظهر فقط لو الخبير نفسه ضغط زر "أضف هبوطًا بديلًا لهذا المقام؟" وهو واقف
على عنصر "هبوط شائع" لمقام لم يُضَف له هبوط بديل بعد بنفس الجلسة. الضغط
يُدرِج عنصرًا جديدًا مباشرة بعد العنصر الحالي في قائمة الجلسة الحيّة
(`sessionItems`، نسخة قابلة للتعديل من `INTAKE_SESSION_ITEMS` الثابتة)،
ويكبّر العدد الإجمالي المعروض فورًا — لا افتراض مسبق لأي مقام (رست فقط
مؤكَّد بمصادر قوية بالسجل، الباقي "؟"، القرار 13.2). لا يُسمح بأكثر من
هبوط بديل واحد لكل مقام بنفس الجلسة.

**لم يُنفَّذ بعد ضمن هذي البنية:** حقل "النغمة المتغيّرة" متعدد الاختيار
عند تفعيل الهبوط البديل (القرار 13.3) — مرحلة منفصلة تالية.

  خطوة منفصلة تالية، تنتظر وجود ملفات فعلية من جلسة خبير حقيقية أولًا).
- صفحة "من نحن" التي تعرض قائمة الخبراء المسجَّلين (القرار 9.5).
- خيار الرفع المباشر لـGoogle Drive (نقطة مفتوحة غير محسومة، القرار 9.4).
- **باقي القسم 13 (توسيع مكتبة الاستماع) — مراحل مستقلة لاحقة، لم تُنفَّذ بعد:**
  - 13.3: حقل "النغمة المتغيّرة" متعدد الاختيار عند تفعيل الهبوط البديل.
  - 13.4: تحقّق الهوية بصوت الخبير داخل نفس التسجيل (تعديل نص `hint` فقط).
  - 13.5: تمهيد أربع عدّات بمترونوم بصري قبل بداية التسجيل الفعلي.
  - 13.6: الفصل التلقائي لصوت الخبير عن النغمة (قصّ عند فجوة صمت) → نسختان
    (خام/نظيفة).
  - 13.7: تجربة تسجيل احترافية إضافية (مسح المحاولة، قائمة تقدّم مرئية
    كاملة تفصل المكتمل عن المتبقي).
  - **ما تمّ فعليًا حتى الآن (13.1 + 13.2):** توسيع `expert-intake-data.js`
    (100 نغمة بدل 25، `RHYTHMIC_VALUES` — القرار 13.1) + بنية المقام
    الثلاثية (صعود + هبوط شائع إلزاميان، هبوط بديل اختياري يُدرَج حيًّا
    عبر زر بصفحة الخبير — القرار 13.2)، بلا أي تغيير على
    `expert-recorder.js` أو منطق التسجيل نفسه.
