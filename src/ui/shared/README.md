# src/ui/shared/

ملفات مشتركة بين أكثر من صفحة واحدة، خارج مجلد أي صفحة فردية. أول ملف
هنا: `nav.js` — تنقّل عام موحَّد بين الصفحات.

## nav.js — التنقّل العام الموحَّد

**الحالة: مدموج فعليًا في كل الصفحات السبع المبنية عبر JS، بالإضافة لنسخة HTML ثابتة يدويًا في صفحة #8**

| الملف | الدور |
|---|---|
| `nav.js` | `mountNav(container, currentKey)` — يبني شريط تنقّل بروابط للصفحات الثماني كلها، يُبرز الصفحة الحالية عبر `currentKey`. كل الصفحات أخوات بنفس العمق (`src/ui/pages/XX-name/index.html`)، فالمسار النسبي بين أي صفحتين ثابت الصيغة دائمًا (`../YY-name/index.html`) — لا حساب عمق مختلف حسب الصفحة المصدر. |
| `tests/nav-smoke.test.mjs` | 4 اختبارات Playwright دخان: كل الروابط الثمانية موجودة وصحيحة على صفحتين ممثلتين (الرئيسية والمقامات)، تمييز الصفحة الحالية صحيح على كل منهما، تنقّل فعلي حقيقي من رابط في الشريط يصل بنجاح لصفحة أخرى عاملة، وتحقق من نسخة صفحة #8 الثابتة يدويًا (نفس الروابط، بلا أي `<script>`). |

## استثناءان مقصودان

- **صفحة #8 (الدليل التعليمي):** لا تستورد `nav.js` — لديها نسخة HTML ثابتة
  يدويًا من نفس بنية الشريط وأصنافه، لأن الصفحة بقرار صريح "بلا JavaScript
  إطلاقًا" (القرار 6). النسختان متطابقتان بصريًا ووظيفيًا (روابط، تمييز
  الحالة)، لكن واحدة مبنية ديناميكيًا والأخرى مكتوبة حرفيًا في HTML.
- **صفحة #3 (التمارين):** لا تحتوي شريط تنقّل — هي مجرد إعادة توجيه فورية
  (`meta refresh content="0"`) لصفحة المنهج الحقيقية، تظهر لحظيًا إن ظهرت
  أصلًا قبل التنقّل التلقائي؛ إضافة شريط هنا بلا فائدة عملية.
- **صفحة المنهج الحقيقية نفسها** (`src/exercises/legacy-miran/index.html`)
  لا تحتوي الشريط أيضًا — ملف محمي (`src/exercises/**`)، لا يُعدَّل إلا
  بقرار صريح جديد.

