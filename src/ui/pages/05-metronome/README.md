# 05 — المترونوم

مستقل، بجدولة lookahead المحسّنة. نفس محرك `src/metronome/` المستخدم في صفحة
المعايرة (#2) — مصدر حقيقة واحد للكود، تختلف الواجهة فقط.

## الحالة: مدموجة فعليًا — واجهة كاملة تعمل، مبنية على `metronome-ui-full.js` الجاهز مسبقًا

## البنية

| الملف | الدور |
|---|---|
| `index.html` | غلاف HTML بسيط، يستورد `mountFullMetronome` من `src/metronome/metronome-ui-full.js` مباشرة ويربطه بعنصر `#app`. لا منطق خاص بهذي الصفحة — كل التوقيت والحالة داخل `MetronomeEngine`. |
| `tests/page-smoke.test.mjs` | 6 اختبارات Playwright دخان (تحميل بلا أخطاء، عناصر الواجهة الأساسية، عدد مؤشرات النبضة يطابق الميزان الافتراضي 4، تحديث BPM من الشريط، إعادة بناء المؤشرات عند تغيير الميزان إلى 3، تبديل زر التشغيل/الإيقاف بلا استثناء غير مُعالَج). |

## قرار تقني اتُّخذ في هذي المرحلة

لا يوجد ملف منطق منفصل للصفحة (بخلاف صفحة #2 التي لها `calibration-page.js`) —
`mountFullMetronome` مكتمل الوظائف بالفعل (شريط BPM، اختيار الميزان، مؤشرات
بصرية، زر تشغيل/إيقاف) ولا يحتاج طبقة تنسيق إضافية. `index.html` يستدعيه
مباشرة، حفاظًا على مصدر الحقيقة الواحد للكود (القسم 7 من سجل القرارات).

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم **جذر المستودع** (المسار النسبي للوحدة يتجاوز مجلد
الصفحة نفسها إلى `src/metronome/`):

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/05-metronome/tests/page-smoke.test.mjs
```

- تنبيه بصري بديل لمن لا يعتمد على الصوت (اهتزاز/وميض) — لم يُطلب صراحة بعد
  (نفس البند المفتوح في `src/metronome/README.md`).
- حفظ آخر إعداد BPM/ميزان محليًا بين الزيارات — لم يُطلب صراحة بعد.
