# 01 — الرئيسية

نظرة عامة، تقدّم المتعلم، دخول سريع للمرحلة الحالية. تقرأ من بيانات التقدّم المحلية
(معرّف المستخدم المحلي — انظر القسم 6 من سجل القرارات لتحضير البيانات المستقبلي).

## الحالة: مدموجة فعليًا — آخر صفحة من خريطة الصفحات الثماني (القسم 7)، تربط كل الصفحات السبع المبنية سابقًا

## البنية

| الملف | الدور |
|---|---|
| `index.html` | غلاف HTML بسيط، يحمّل `home-page.js` كوحدة ES. |
| `home-page.js` | يجمّع ملخص تقدّم من ثلاثة مصادر مقروءة (لا مُعاد بناؤها): (1) تقدّم المنهج عبر قراءة مباشرة لمفتاح `localStorage` الخام `miran_prog` كما يكتبه `persistence.js` المحمي في `src/exercises/legacy-miran/` — قراءة فقط، بلا استيراد لذلك الملف نفسه؛ (2) ملخص المعايرة بإعادة استخدام `loadRawState` من صفحة #2 و`PersonalReferenceStore`/`CalibrationSample` من `src/calibration/` (نفس نمط صفحة #6)؛ (3) المعرّف المحلي بإعادة استخدام `getOrCreateLocalUserId` من صفحة #7. يبني أيضًا شبكة "دخول سريع" لكل الصفحات السبع، مع تمييز صفحة التمارين (#3) كرابط رئيسي بارز ("المرحلة الحالية"). |
| `tests/page-smoke.test.mjs` | 6 اختبارات Playwright دخان: تحميل بلا أخطاء، حالة فارغة (كل العدّادات صفر)، كل روابط الدخول السريع السبعة موجودة بمساراتها الصحيحة والرابط الرئيسي يشير لصفحة التمارين، ثبات المعرّف المحلي عبر إعادة التحميل، تقدّم منهج مزروع يظهر بشكل صحيح، بيانات معايرة مزروعة تظهر بشكل صحيح. |

## خطأ اكتُشف وصُحِّح أثناء هذي المرحلة

الحساب الأول لعدد "المراجع المعتمَدة" كان يستدعي `store.getFrozenReference`
بلا استدعاء `store.restoreFrozenSnapshot` أولًا عند إعادة بناء المخزن من
البيانات الخام — فيرجع `null` دائمًا (0 مهما وُجدت لقطات معتمدة فعليًا).
اختبار "بيانات معايرة مزروعة" (توقّع مرجعًا معتمَدًا واحدًا) كشف الخطأ فورًا
قبل الدفع؛ صُحِّح بإضافة حلقة `restoreFrozenSnapshot` (نفس النمط الموجود
في `calibration-page.js` و`library-page.js`).

## قرار تقني اتُّخذ في هذي المرحلة

**لا استيراد لأي ملف من `src/exercises/legacy-miran/`، حتى للقراءة.**
`persistence.js` ملف محمي (`src/exercises/**` في `ARCHITECTURE.md`)، وهو
سكربت كلاسيكي غير قابل للاستيراد كوحدة ES أصلًا (نفس السبب المذكور في
README صفحة #2 لعدم استيراد جدول الإصبعات). القراءة المباشرة لمفتاح
`localStorage` الخام (`JSON.parse(localStorage.getItem('miran_prog'))`)
تكشف نفس بنية البيانات التي تفحصها `home-render.js` الأصلية
(`Object.keys(prog.done).length`) دون لمس الملف المحمي نفسه أو تكرار
منطقه — قراءة بيانات، لا استيراد كود.

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم **جذر المستودع** (المسارات النسبية للوحدات تتجاوز
مجلد الصفحة نفسها إلى `src/calibration/`، `src/ui/pages/02-calibration/`،
و`src/ui/pages/07-settings-sync/`):

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/01-home/tests/page-smoke.test.mjs
```

## لم يُبنَ بعد (خارج نطاق هذي المرحلة)

- تنقّل عام موحَّد (شريط علوي) عبر بقية الصفحات نفسها — حاليًا فقط الرئيسية
  تربط للبقية، لا رابط رجوع موحَّد من كل صفحة للرئيسية.
- عرض تقدّم دليل المقامات (مصادقة السِّير) ضمن ملخص التقدّم — القرار 5 لا
  يوفّر بعد آلية تسجيل مصادقة من داخل الواجهة (موثَّق كفجوة في README صفحة #4).
