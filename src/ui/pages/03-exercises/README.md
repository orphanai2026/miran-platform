# 03 — التمارين

كامل منهج الـ74 يومًا كما هو. منقول كاملًا من `src/exercises/`، بلا تعديل بنيوي.

## الحالة: إطار مضمّن (iframe) تحت شريط رجوع ثابت لصفحة #1

## البنية

| الملف | الدور |
|---|---|
| `index.html` | شريط علوي ثابت (44px، بلا JavaScript) فيه رابط رجوع واحد لصفحة #1 (الرئيسية)، وتحته `<iframe>` يحمّل `src/exercises/legacy-miran/index.html` بمساحة الشاشة الباقية كاملة. |
| `tests/page-smoke.test.mjs` | اختباران: (1) شريط الرجوع موجود ويشير للمسار الصحيح، (2) الإطار المضمّن يحمّل صفحة المنهج الحقيقية بلا 404 ولا استثناء JS (`#view-home` يظهر داخل الإطار). |

## سبب التعديل هذي المرحلة

نقطة الدخول الأصلية كانت توجيهًا فوريًا (`meta http-equiv="refresh"`) يُخرج
المستخدم من نطاق المنصة كليًا لصفحة `legacy-miran/index.html` المستقلة —
تلك الصفحة (منقولة حرفيًا، بلا أي شريط تنقّل موحَّد) لا تحتوي أي رابط رجوع
للمنصة، فيعلق المستخدم بلا طريق عودة سوى زر رجوع المتصفح نفسه. الحل: إطار
مضمّن (iframe) بدل التوجيه، مع شريط رجوع ثابت خارج الإطار في صفحة #3 نفسها
(آمنة للتعديل الحر) — **بلا أي لمس لملف المنهج المحمي** (`src/exercises/**`
في `ARCHITECTURE.md`)، يُحمَّل بداخل الإطار حرفيًا كما هو.

## لماذا إطار مضمّن لا صفحة مبنية من جديد

نفس القيد الأصلي لا يزال ساريًا: القرار الصريح في سجل القرارات (القسم 4
والقسم 7) هو "منقول كاملًا من مِران، **بلا تعديل بنيوي**." إعادة بناء واجهة
كاملة جديدة هنا كانت ستعني إما مخالفة "بلا تعديل بنيوي" بلمس الملفات
المحمية، أو تكرار منطق كامل (4255 سطرًا أصليًا) في مكان ثانٍ. الإطار
المضمّن يحل مشكلة الرجوع بالكامل خارج حدود الملف المحمي.

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم جذر المستودع:

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/03-exercises/tests/page-smoke.test.mjs
```
