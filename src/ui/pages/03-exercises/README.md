# 03 — التمارين

كامل منهج الـ74 يومًا كما هو. منقول كاملًا من `src/exercises/`، بلا تعديل بنيوي.

## الحالة: مدموجة فعليًا — نقطة دخول رقيقة تُعيد التوجيه للمنهج الحقيقي العامل والمُختبر

## البنية

| الملف | الدور |
|---|---|
| `index.html` | صفحة HTML صغيرة جدًا (بلا JavaScript) تحمل `<meta http-equiv="refresh" content="0">` توجّه فورًا لـ `src/exercises/legacy-miran/index.html`، بالإضافة لرابط رجوع يدوي احتياطي إن تعذّر التوجيه التلقائي (متصفحات نادرة تعطّله). |
| `tests/page-smoke.test.mjs` | اختباران: (1) فحص مصدر HTML الخام مباشرة (لا متصفح — التوجيه فوري `content="0"` فيتسابق أي فحص DOM حي معه) للتأكد من صحة رابطي التوجيه التلقائي واليدوي، (2) تنقّل فعلي في متصفح حقيقي يتحقق من وصول التوجيه لصفحة المنهج الحقيقية بلا أخطاء 404 أو استثناءات JS، وظهور `#view-home`. |

## لماذا نقطة دخول لا صفحة مبنية من جديد

القرار الصريح في سجل القرارات (القسم 4 والقسم 7) هو: منهج الـ74 يومًا
"منقول كاملًا من مِران، **بلا تعديل بنيوي**." هذا المنهج منقول ومُختبر فعليًا
بالكامل في `src/exercises/legacy-miran/` (باندماج `baseline-regression.test.mjs`
9/9 ناجح). هذا المسار محمي صراحة في `ARCHITECTURE.md` تحت "ملفات حساسة —
لا تُعدَّل إلا بقرار صريح جديد". إعادة بناء واجهة كاملة جديدة هنا كانت
ستعني إما (أ) مخالفة "بلا تعديل بنيوي" بلمس الملفات المحمية، أو (ب) تكرار
منطق كامل (4255 سطرًا أصليًا) في مكان ثانٍ — يخالف "مصدر حقيقة واحد لكل
بيانة" (القسم 4). التوجيه الرقيق هو الحل الوحيد المطابق حرفيًا لكل القيود
المذكورة، ويمنح صفحة #3 نقطة وصول حقيقية ضمن خريطة الصفحات الثماني (القسم 7)
دون أي مخاطرة على المنهج المُختبر.

## خطأ اكتُشف وصُحِّح أثناء هذي المرحلة

المسار النسبي الأول المكتوب كان خاطئًا (`../../exercises/...` بمستويين فقط)
— أدى فعليًا لطلب `/src/ui/exercises/legacy-miran/index.html` (404)، لأن
`src/ui/pages/03-exercises/` يحتاج **ثلاثة** مستويات صعودًا للوصول لجذر
`src/` (نفس عمق `../../../calibration/` المستخدم في صفحة #2). صُحِّح إلى
`../../../exercises/legacy-miran/index.html`، واختبار التنقّل الفعلي في
متصفح حقيقي (لا فحص نص فقط) هو ما كشف الخطأ فعليًا قبل الدفع.

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم جذر المستودع:

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/03-exercises/tests/page-smoke.test.mjs
```
