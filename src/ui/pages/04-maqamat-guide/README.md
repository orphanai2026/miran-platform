# 04 — دليل المقامات

السلم (سلسلة الأجناس) والسِّير اللحني لكل مقام (القرار 5). يعرض علامة "؟"
صريحة لكل سِّير غير مصادَق عليه.

## الحالة: مدموجة فعليًا — واجهة تعمل، تعرض ALL_MAQAMAT من src/maqamat/ مباشرة

## البنية

| الملف | الدور |
|---|---|
| `index.html` | غلاف HTML بسيط، يحمّل `maqamat-page.js` كوحدة ES. |
| `maqamat-page.js` | يستورد `ALL_MAQAMAT` من `src/maqamat/maqam-data.js` مباشرة (لا نسخ بيانات — مصدر حقيقة واحد، القسم 4). يبني قائمة أزرار بعدد المقامات، ولوحة تفاصيل تعرض القرار/الغماز/سلسلة الأجناس (كل جنس: اسمه، درجة البداية، نمط الأبعاد مترجَمًا للعربية، مصدره الموثَّق) وحالة السِّير. |
| `tests/page-smoke.test.mjs` | 5 اختبارات Playwright دخان (تحميل بلا أخطاء، عدد أزرار القائمة يطابق ALL_MAQAMAT، أول مقام محدَّد تلقائيًا، الضغط على مقام آخر يحدّث اللوحة، كل مقام يعرض علامة "؟" لأن كل sayr=null حاليًا). |

## نطاق مقصود لهذي المرحلة

عرض قراءة فقط للسلم والسِّير المسجَّلين مسبقًا في `src/maqamat/maqam-data.js`.
**لا يتضمن إرشادًا صوتيًا تفاعليًا** (مقارنة عزف حي بالسِّير عبر الميكروفون) —
ذلك يحتاج دمجًا مع `src/calibration/` ولم يُطلب صراحة بعد. بما أن كل قيم
`sayr` في `maqam-data.js` حاليًا `null`، كل مقام يعرض "لم يُسجَّل السِّير
اللحني بعد ؟" — هذا سلوك متوقَّع ومطابق للقرار 5 (لا اعتماد افتراضي).

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم **جذر المستودع** (المسار النسبي للوحدة يتجاوز مجلد
الصفحة نفسها إلى `src/maqamat/`):

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/04-maqamat-guide/tests/page-smoke.test.mjs
```

## لم يُبنَ بعد (خارج نطاق هذي المرحلة)

- تسجيل مصادقة سِّير فعلية من داخل الواجهة (استدعاء `validateSayr`) — حاليًا
  المصادقة تتم برمجيًا فقط عبر `src/maqamat/maqam-schema.js`، لا واجهة إدخال.
  يحتاج أولًا استخراج سِّير فعلي موثَّق لكل مقام (كل القيم حاليًا `null`).
- إرشاد ذاتي صوتي (مقارنة عزف حي بالسِّير) — رؤية القسم 2 الأوسع، غير مبنية بعد.

## تحديث لاحق: فجوة جنس راست العلوي أُغلِقت

كانت هذي القائمة تذكر "إكمال جنس راست العلوي الناقص عمدًا" كفجوة مفتوحة — أُغلِقت
في مرحلة لاحقة ببحث مباشر في MaqamWorld (تفاصيل كاملة في `src/maqamat/README.md`).
مقام راست الآن يعرض جنسين بدل واحد في هذي الصفحة.
