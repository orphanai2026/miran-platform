# 07 — الإعدادات + المزامنة

نقل البيانات، إعدادات السماحية، كود المزامنة. يحمل معرّف المستخدم المحلي
بشكل صريح هنا تحديدًا (القسم 7، تحصين بيانات القسم 6).

## الحالة: مدموجة فعليًا — كود المزامنة يُولَّد ويثبت محليًا، إعدادات السماحية معروضة، رابط لصفحة التصدير

## البنية

| الملف | الدور |
|---|---|
| `index.html` | غلاف HTML بسيط، يحمّل `settings-sync-page.js` كوحدة ES. |
| `local-user-id.js` | معرّف المستخدم المحلي (كود المزامنة) — يولّده عبر `crypto.randomUUID()` عند أول استخدام ويخزّنه في `localStorage` (مفتاح جديد `miran_local_user_id_v1`، منفصل تمامًا عن مفتاح صفحة #2/#6)، ثابت بعدها لا يتغيّر تلقائيًا. تحصين بيانات القسم 6 (لا فتح لقرار الحسابات/الاشتراكات الكامل). |
| `settings-sync-page.js` | يستدعي `getOrCreateLocalUserId()`، يستورد `STARTING_TOLERANCE_CENTS_MIN`/`MAX` مباشرة من `src/calibration/calibration-engine.js` (لا تكرار قيم)، ويبني ثلاثة أقسام: كود المزامنة، إعدادات السماحية (عرض فقط)، ونقل البيانات (رابط لصفحة #6 + توضيح أن الإرسال الشبكي الفعلي غير مبني بعد). |
| `tests/page-smoke.test.mjs` | 5 اختبارات Playwright دخان (تحميل بلا أخطاء، شكل المعرّف المولَّد صحيح، ثبات المعرّف عبر إعادة التحميل، عرض حدود السماحية الصحيحة ±10/±25، رابط صفحة المكتبة/التصدير صحيح). |

## قرارات تقنية اتُّخذت في هذي المرحلة

- **إعدادات السماحية عرض فقط، لا تعديل.** `STARTING_TOLERANCE_CENTS_MIN`/`MAX`
  ثابتان مُصدَّران من `calibration-engine.js` ويُستخدَمان فعليًا في حساب
  السماحية المشتقة (القرار 2)، الذي 16 اختبارًا قائمًا يعتمد على قيمهما
  الحالية. إضافة تحكّم تفاعلي لتعديلهما من هذي الصفحة كان سيفتح منطق القرار
  2 الحسابي بلا طلب صريح لذلك — تُركت عرضًا توضيحيًا فقط حاليًا.
- **لا إرسال شبكي فعلي.** القسم يشرح أن استثناء القرار 4 (نقطة استقبال
  Cloudflare) غير مبني بعد، ويوجّه لصفحة #6 للتصدير المحلي فقط — لا فتح
  لقرار الحسابات/الاشتراكات (القسم 6) ولا محاولة بناء الاستثناء الفعلي بلا
  طلب صريح.
- **مفتاح `localStorage` جديد ومنفصل** (`miran_local_user_id_v1`) لا يتقاطع
  مع مفتاح بيانات المعايرة في صفحة #2/#6 (`miran_calibration_samples_v1`) —
  كل بيانة في مكانها الخاص، لا تكرار ولا تداخل.

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم **جذر المستودع** (المسار النسبي للوحدة يتجاوز مجلد
الصفحة نفسها إلى `src/calibration/`):

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/07-settings-sync/tests/page-smoke.test.mjs
```

## لم يُبنَ بعد (خارج نطاق هذي المرحلة)

- الإرسال الشبكي الفعلي (استثناء القرار 4، نقطة استقبال Cloudflare) —
  التصدير المحلي فقط متاح حاليًا عبر صفحة #6.
- تحكّم تفاعلي لتعديل حدود السماحية — عرض فقط حاليًا (انظر أعلاه).
- ربط الصفحة الرئيسية (#1) أو صفحات أخرى بمعرّف المستخدم المحلي لقراءة
  بيانات تقدّم مرتبطة به — لم يُبنَ بعد.
