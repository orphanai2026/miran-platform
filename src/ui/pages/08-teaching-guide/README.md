# 08 — الدليل التعليمي

توصية الخروج لمعلم بشري عند الطبقة 3 (القرار 6). نص إرشادي ثابت، لا تفاعلي.

## الحالة: مدموجة فعليًا — صفحة HTML/CSS ثابتة بالكامل، بلا JavaScript

## البنية

| الملف | الدور |
|---|---|
| `index.html` | كل محتوى الصفحة — عرض الطبقات الثلاث من القرار 6 (مضمونة بالكامل / مضمونة لاحقًا / خارج الضمان) وتوصية صريحة بمعلم بشري عند الطبقة الثالثة. **لا وحدة ES، لا سكربت من أي نوع** — مطابقة حرفية لنص القرار 6 والقسم 7: "نص إرشادي ثابت، لا تفاعلي". |
| `tests/page-smoke.test.mjs` | 4 اختبارات Playwright دخان (تحميل بلا أخطاء، الطبقات الثلاث موجودة بمحتواها الصحيح، توصية المعلم البشري ظاهرة، تأكيد عدم وجود أي وسم `<script>` في الصفحة). |

## قرار تقني اتُّخذ في هذي المرحلة

**لا JavaScript على الإطلاق.** هذي الصفحة الوحيدة من الصفحات الثماني التي لا
تستورد أي محرك أو وحدة ES — القرار 6 ينص صراحة على أن هذا "نص إرشادي ثابت،
لا تفاعلي"، وأي منطق برمجي هنا كان سيخالف ذلك حرفيًا بلا داعٍ حقيقي.

## اختبار قبل أي تعديل مستقبلي

يحتاج خادمًا محليًا يخدم جذر المستودع (لا استيراد وحدات فعليًا، لكن نفس
النمط الموحَّد للاختبارات):

```bash
python3 -m http.server 8934 --directory /path/to/miran-platform
node src/ui/pages/08-teaching-guide/tests/page-smoke.test.mjs
```
