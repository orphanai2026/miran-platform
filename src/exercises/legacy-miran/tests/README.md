# tests/ (داخل legacy-miran/)

اختبارات Playwright تغطي السلوك الحالي لـ `index.html` كخط أساس (baseline) —
**قبل** أي تفكيك للملف إلى وحدات منفصلة.

## لماذا هذا الملف موجود

سجل القرارات يذكر أن التمارين "مُختبرة بانحدار Playwright كامل"، لكن
`github.com/orphanai2026/miran` (المصدر الأصلي) لا يحتوي فعليًا أي ملفات اختبار.
بدل تفكيك 4255 سطرًا من كود مترابط بإحكام (متغيرات عامة مشتركة بين الأقسام) بلا
شبكة أمان، كُتبت هذه الاختبارات أولًا لتوثيق السلوك الحالي كخط أساس أخضر —
أي تفكيك لاحق يجب أن يمر بنفس هذه الاختبارات دون تغيير.

## النطاق المقصود

اختبارات تنقّل/عرض/بيانات فقط. **لا تغطي التقاط ميكروفون فعلي** (بيئة headless
بلا جهاز صوت حقيقي) — أي منطق صوتي (كشف النغمة، المعايرة الفعلية) خارج نطاق
هذا الخط الأساس عمدًا؛ التحقق منه يبقى يدويًا (بمتصفح حقيقي بميكروفون).

## سلوكيات حقيقية اكتُشفت أثناء كتابة الاختبارات (موثّقة هنا لتفادي إعادة اكتشافها)

1. **`btnCalibSeg` يُخفى عمدًا بمنطق شرطي**: `$('btnCalibSeg').style.display =
   useThread ? 'none' : ''` — عند استخدام تصميم "الخيط" (thread) لليوم الحالي،
   يظهر بدلًا منه `#calibWaitingStation`. هذا سلوك مقصود، لا خلل. الاختبار
   الأول افترض ظهور `btnCalibSeg` دائمًا، وكان غلطًا مني.
2. **`CURRICULUM` و`LEVELS` مُعرَّفان بـ `const`**، لا `var` — هذا يعني لا
   تُنشأ خاصية على `window` تلقائيًا في المتصفح (بعكس `var`). محاولة قراءة
   `window.CURRICULUM` من خارج السكربت ترجع `undefined` دائمًا رغم أن
   البيانات مُحمَّلة وتُستخدم فعليًا. الدليل الموثوق هو العرض الفعلي في DOM.
3. **طلبات خطوط Google الخارجية (`fonts.googleapis.com`) محجوبة** في بيئة
   العمل هذي بسياسة شبكة مقيدة بنطاقات محددة — غير متعلق بالتطبيق نفسه.
   الاختبارات تفلتر هذا صراحة.

## التشغيل

يحتاج خادمًا محليًا يخدم `index.html` أولًا:

```bash
cd src/exercises/legacy-miran
python3 -m http.server 8934 --bind 127.0.0.1 &
cd ../../.. # للجذر
node src/exercises/legacy-miran/tests/baseline-regression.test.mjs
```

**يحتاج حزمة `playwright`** مثبَّتة (أداة تطوير/اختبار فقط، لا جزء من الوعد
"بلا اعتماديات تشغيل" — الاعتماديات هنا لا تُشحَن مع الملف النهائي، فقط تُستخدم
وقت التطوير للتحقق).

## الحالة الحالية: 9/9 اختبارات ناجحة — قبل وبعد التفكيك

هذا الخط الأساس أثبت دوره فعليًا: **9/9 ناجحة على `index.html` الأصلي غير
المُعدَّل**، ثم **9/9 ناجحة مجددًا بعد تفكيك الملف فعليًا** إلى وحدات منفصلة
(`js/` + `legacy-calibration-do-not-reuse/`) دون تعديل أي سطر في هذا الملف
نفسه. تفاصيل التفكيك وخريطة الأسطر الكاملة في `../SPLIT-NOTES.md`.
