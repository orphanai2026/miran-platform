# build/

خطوة دمج بسيطة **بلا مكتبات خارجية**، تُشغَّل وقت النشر فقط، تنتج ملفًا
واحدًا نهائيًا لكل صفحة (بلا خادم، بلا اعتماديات تشغيل) — الوعد الأصلي
لمِران محفوظ بالكامل للمستخدم النهائي.

## الحالة: مبنية فعليًا ومُختبرة — أداة دمج مكتوبة يدويًا، بلا esbuild/rollup/أي حزمة npm

## التشغيل

```bash
node build/build.mjs
```

ينتج `build/dist/` (غير مُتتبَّع في git، مذكور ضمن `dist/` في `.gitignore`
الجذري):

```
build/dist/
├── 01-home/index.html              (مدموج، مستقل تمامًا)
├── 02-calibration/index.html       (مدموج، مستقل تمامًا)
├── 03-exercises/index.html         (نسخة مع تعديل عمق المسار النسبي فقط)
├── 04-maqamat-guide/index.html     (مدموج، مستقل تمامًا)
├── 05-metronome/index.html         (مدموج، مستقل تمامًا)
├── 06-library-export/index.html    (مدموج، مستقل تمامًا)
├── 07-settings-sync/index.html     (مدموج، مستقل تمامًا)
├── 08-teaching-guide/index.html    (نسخة حرفية، بلا JS أصلًا)
└── exercises/legacy-miran/         (نسخة كاملة حرفية — بلا تعديل بنيوي)
```

## لماذا هذي الأداة ضرورية — ليست تحسينًا اختياريًا

كل الصفحات الست المبنية بوحدات ES (`import`/`export`) **تحتاج خادم HTTP
لتعمل** — المتصفحات تمنع تحميل وحدات ES عبر بروتوكول `file://` (قيود
CORS). لهذا كل اختبارات الصفحات في المستودع تشغّل
`python3 -m http.server` أولًا. لو فتح مستخدم نهائي أي صفحة بالنقر المزدوج
مباشرة، ستفشل بصمت أو بخطأ CORS — **يخالف صراحة الوعد التأسيسي المكتوب في
`ARCHITECTURE.md` منذ اليوم الأول**: "ملف واحد نهائي، بلا خادم، بلا
اعتماديات تشغيل". هذي الأداة تسدّ تلك الفجوة فعليًا، لا نظريًا.

## البنية

| الملف | الدور |
|---|---|
| `build.mjs` | أداة الدمج الكاملة. تحلّل كل ملف JS (بحث نصي عن أسطر `import`/`export`، لا محلّل JS كامل — يكفي لأن كل الاستيرادات في المشروع بصيغة واحدة بسيطة: `import { a, b } from "./path.js";`، بلا default/namespace/alias imports، تحقَّق منه فعليًا قبل الكتابة). تبني رسمًا بيانيًا للتبعيات، ترتّبه طوبولوجيًا (تبعيات قبل معتمِديها)، تزيل بادئة `export`، وتُلحق كل الملفات في `<script>` واحد داخل IIFE واحدة (`(function(){...})()`) لعزل النطاق. **تكتشف تعارض الأسماء تلقائيًا** (لو عُرِّف نفس الاسم في ملفين ضمن نفس حزمة صفحة) وترمي خطأً واضحًا بدل إنتاج كود مكسور بصمت. |
| `tests/build-output.test.mjs` | **الاختبار الحقيقي.** يفتح كل صفحات `build/dist/` عبر `file://` مباشرة — **بلا أي خادم HTTP إطلاقًا** — ويتحقق من: تحميل بلا أخطاء، عناصر DOM أساسية، تفاعل فعلي (تشغيل/إيقاف مترونوم، تبديل مقام)، وتنقّل فعلي حقيقي بالنقر على رابط بين صفحتين مدموجتين مختلفتين (يبقى `file://` طوال الوقت). 9/9 ناجح. |

## تفسير "ملفًا واحدًا نهائيًا" المتَّبع هنا — يستحق مراجعتك

نص القرار 4 حرفيًا: *"خطوة دمج بسيطة بلا مكتبات خارجية وقت النشر تنتج
ملفًا واحدًا نهائيًا."* لكن خريطة الصفحات الثماني (القسم 7، قرار مُقفَل)
تنص على **ثماني صفحات منفصلة بروابط مستقلة**. هذان النصان يتعارضان حرفيًا
لو قُرئ "ملف واحد" على أنه ملف واحد للمنصة الثمانية **كاملة**.

للتوفيق بينهما دون فتح أي منهما صراحة: هذي الأداة تنتج **ملفًا نهائيًا
واحدًا مستقلًا تمامًا لكل صفحة على حدة** — نفس روح "ملف واحد" التي كانت
عليها مِران الأصلية (كانت هي نفسها صفحة واحدة، ملف واحد، قبل التوسّع
لثماني صفحات). كل ملف مخرَج يفتح بمفرده بلا خادم، بلا اعتماديات — الوعد
محقَّق على مستوى كل صفحة.

**لو كان المقصود الفعلي** ملفًا واحدًا حرفيًا للمنصة الثمانية كاملة (توجيه
داخلي بتبديل "views" بدل روابط/URLs منفصلة بين ملفات — كما كانت مِران
الأصلية بالضبط قبل تقسيمها) — هذا **يحتاج قرارًا صريحًا جديدًا يعيد فتح
خريطة الصفحات نفسها (القسم 7)**، ولم يحدث ذلك. تحسين هذي الأداة لاحقًا
لتنتج ملفًا واحدًا حرفيًا للمنصة كاملة ممكن، لكنه تغيير معماري أكبر من مجرد
تحسين على أداة الدمج — يستحق نقاشًا صريحًا منفصلًا لو كان هذا هو المقصود
فعلًا.

## اختبار قبل أي تعديل مستقبلي

```bash
node build/build.mjs                    # يبني build/dist/
node build/tests/build-output.test.mjs   # يختبرها عبر file:// بلا خادم
```

## لم يُبنَ بعد (خارج نطاق هذي المرحلة)

- تصغير/ضغط الكود المدموج (minification) — لم يُطلب صراحة، والقرار
  "بلا مكتبات خارجية" يجعل كتابة مُصغِّر JS يدويًا مخاطرة غير مبرَّرة حاليًا.
- خيار "ملف واحد حرفي للمنصة كاملة" الموصوف أعلاه — يحتاج قرارًا صريحًا
  جديدًا يعيد فتح خريطة الصفحات (القسم 7).
- تشغيل تلقائي للدمج (CI/CD) عند كل دفع لـ GitHub — لم يُطلب صراحة بعد.
