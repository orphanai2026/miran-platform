# مِران — منصة تعليم الناي الموحدة

منصة تعليم الناي الشرقي، بلا خادم (باستثناء ضيق موثّق)، تدمج:

- **منهج مِران** (74 يومًا، 6 مستويات) لإتقان الآلة.
- **روح RECORD-N** (معايرة، توثيق نغمة شخصي، مترونوم) لضمان صحة النغمة قبل التدريب.

هذا المستودع نقطة الانطلاق التنفيذية بعد اعتماد سجل القرارات الكامل. **المرجع الوحيد لأي قرار** هو
[`docs/miran-decisions-log.md`](docs/miran-decisions-log.md) — يُقرأ كاملًا قبل أي تعديل بنيوي.

## الحالة الحالية

هذه بنية مجلدات أولية (Scaffold) فقط، وفق خريطة الصفحات الثماني المعتمدة (القسم 7 من سجل القرارات)
والقواعد المعمارية (القسم 4). لا يوجد كود تنفيذي بعد — كل مجلد يحوي `README.md` يوضح مسؤوليته
ومرجعه في سجل القرارات، تمهيدًا للتنفيذ الفعلي في محادثات لاحقة، مرحلة واحدة في كل مرة.

## البنية

```
src/
  exercises/     تمارين مِران الـ74 يومًا — تُنقل كأكواد كما هي، لا تُعاد كتابتها
  calibration/   المعايرة، التسجيل، توثيق النغمة الشخصية (روح RECORD-N، لا نسخ حرفي)
  metronome/     محرك مترونوم واحد (lookahead scheduler)، يُستخدم في صفحتين (#2 و #5)
  maqamat/       بناء السلالم والسِّير اللحني والمصادقة السمعية
  ui/pages/      الصفحات الثماني المعتمدة (انظر القسم 7)
data/            بيانات مصدر الحقيقة الواحدة (سلالم، مقامات، سماحية)
build/           خطوة الدمج وقت النشر → ملف واحد نهائي بلا اعتماديات تشغيل
docs/            سجل القرارات ووثيقة المعمارية
```

## قواعد ثابتة (غير قابلة للتفاوض إلا بقرار صريح جديد)

1. لا خادم إلا استثناء نقل بيانات العازفين (القرار 4) — محصور بطبقة استقبال JSON بسيطة فقط.
2. تمارين مِران تُنقل كما هي، بلا إعادة بناء.
3. أدوات المعايرة/التسجيل/المترونوم تُبنى من جديد بروح RECORD-N، لا بنسخ كودها.
4. مصدر حقيقة واحد لكل بيانة (نغمة، مقام، سماحية) — لا تكرار.
5. ميزة واحدة لكل إصدار + اختبار رجعي كامل قبل كل دمج.

راجع [`ARCHITECTURE.md`](ARCHITECTURE.md) لتفاصيل الملفات الحساسة والآمنة للتعديل.
